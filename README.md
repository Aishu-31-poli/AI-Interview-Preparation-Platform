# 🎯 AI Interview Preparation Platform

An interactive web application designed to help students and job seekers prepare for technical interviews, practice questions, and improve their interview confidence.

## 🚀 Live Demo

🔗 **Website:** [Open AI Interview Preparation Platform](https://Aishu-31-poli.github.io/AI-Interview-Preparation-Platform/)

## ✨ Features

- 💻 **Interview Practice** – Practice interview questions in an interactive environment.
- 📝 **Mock Interviews** – Test your knowledge with mock interview sessions.
- 📊 **Progress Tracking** – Review your practice progress.
- 🌙 **Dark Mode** – Switch between light and dark themes.
- ⚡ **Interactive Interface** – Simple and user-friendly design.
- 🌐 **Browser-Based** – Access the application through a web browser.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## 🖥️ Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/Aishu-31-poli/AI-Interview-Preparation-Platform.git
   ```

2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the Live Server extension in VS Code.
